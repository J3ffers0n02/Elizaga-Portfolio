Capstone Project

San Cristobal Flood Management System (SCFMS) is a multi-platform flood management that supports in mitigating flood related calamities by facilitating in preparedness, mitigation, response, and recovery efforts.

The Login page allows authenticated users to be able to access the mobile application and its features. Users are either barangay staff, responders, or residents.

The Home page contains parts of other features of the mobile application in widgets. This allows users to see a short information regarding other parts of the application.

The News feed page allows barangay staff and responders to post updates that are visible to all the users of the mobile application. These announcements are accompanied by sound notifications to alert the users.

The Status page displays the current hazard level of the river level. The river level is further visualized based on its curent level and how it alligns with the hazard level. Users can select the latest duration that the graph shows.

The Weather page shows shows the weather forecast of Calamba, Laguna. The 3 day forecast is displayed on the page. It includes the current day, and the following next two days. Details on the weather foreacast includes the temperature, humidity, wind speed, precipitation levels, and UV index. The weather page also includes the trends of the wind speed and precipitation of the current day through a graph.

The River status page displays the hazard levels of the current river water level on the map of Purok 5, Barangay San Cristobal

The SOS page shows different features depending on the type of user who accesses this feature. The SOS page(request) allows barangay staff and residents to send SOS distress signal to rescuers if they are in need of rescue.

The SOS page (responder) allows responders to see all active SOS requests. They can navigate to users who've sent an SOS request and be able to respond to them in times of calamities.

In the SOS page(responder), responders can monitor and see total SOS alerts recieved, pending SOS requests, and rescued residents within the day.
